# Project CE

**Project CE** is an **experimental FPS & TPS sci-fi shooter** inspired by *Halo: Combat Evolved*, built and ported for **Roblox** with **full cross-device compatibility**.

Play seamlessly on **Mobile, Desktop, and Console**, with tailored controls, balancing, and performance for each platform.

---

## 🎮 Overview

- **Genre:** FPS / TPS (Experimental)
- **Platform:** Roblox
- **Devices Supported:** Phone, Desktop, Console
- **Server Size:** Up to 16 players
- **Total Plays:** 150,000+  
- **Theme:** Classic sci-fi arena shooter with modern accessibility

## 🎯 Controls

**Default Controls**
- `WASD / Thumbstick` — Move
- `C` — Crouch
- `Space` — Jump
- `Q` — Melee
- `G` — Throw Grenade

Fully remappable via settings.

---

## ⚖️ Cross-Platform Balancing

- **Mobile**
  - Larger hitboxes
  - Sticky aim assistance

- **Console**
  - Sticky aim assistance

- **PC**
  - Precision-focused raw input

All platforms are balanced to remain competitive without compromising skill expression.
